## 🧑‍🚀 About Me

I'm a high school **astronomy teacher** in southern Thailand who builds web apps to make school life easier — for students, for teachers, and for me. I'm an amateur **webmaster** at heart: I love the open web, small useful tools, and running my own stack.

```yaml
role:      High School Astronomy Teacher
location:  Narathiwat, Thailand 🇹🇭
builds:    Educational web apps & school tools
stack:     Google Apps Script · JavaScript · Python
ai_stack:  VPS + Ollama + Telegram Bot + Notion
learning:  Python · automation · self-hosting
motto:     "Look up, then build something useful."
```

## 🚀 What I Build

| | Area | What it looks like |
|:-:|---|---|
| 📚 | **Educational apps** | Interactive lessons and games that make astronomy click for students |
| 🏫 | **School tools** | Student tracking, attendance, grades, and event registration on Apps Script + Sheets |
| 🌐 | **Web utilities** | Small, fast tools — short links, QR codes, image hosting — the webmaster toolkit |
